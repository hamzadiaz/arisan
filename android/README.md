# Arisan Android shell

Solana Mobile web shell (WebView) for the Arisan web app, generated by `solana-mobile webshell init`. Package: `com.arisan.clockin`. This is not a Trusted Web Activity.

Build with the repo script, not by hand:

```bash
ARISAN_WEB_URL=https://<deployment> SOLANA_MOBILE_KEYSTORE_PASSWORD=… ./scripts/build-apk.sh
```

The script sets the URL, version and signing key, then verifies the APK. See [`docs/APK.md`](../docs/APK.md) for requirements, emulator testing and the release checklist.

- `SOLANA_MOBILE_URL` in `gradle.properties` is only a local default; the script overrides it.
- The signing keystore lives outside the repo (`ARISAN_KEYSTORE_PATH`). `twa-manifest.json`'s `signingKey.path` is informational: the CLI does not expand `~`, so the script always passes `--keystore-path`.
- External links outside the configured host open in the system browser. Solana wallet intents are handled natively by the shell.
